# Как взламывают Steam — учебный разбор

Материалы к ролику DreamTeam Development. Сцены с перепиской и входом — вымышленные иллюстрации. Это не демонстрация взлома Steam и не запись реальной атаки.

`HostCheckLab.cpp` — автономная C++17-лаборатория сравнения имён серверов. Нет сетевых запросов, формы входа, работы с паролями, cookies или настоящими аккаунтами. `.example` и `.invalid` используются только для учебных строк.

## Запуск

Создайте консольный проект Visual Studio с C++17, добавьте HostCheckLab.cpp и запустите. Либо соберите локальным компилятором:

```sh
c++ -std=c++17 -Wall -Wextra HostCheckLab.cpp -o HostCheckLab
```

Пять проверок должны завершиться с `Failed tests: 0`. Совпадение имени не доказывает безопасность сайта или действия. Функция ожидает уже выделенный, канонический hostname. Для настоящих URL необходима проверенная библиотека разбора URL и отдельная политика проверки схемы, порта, перенаправлений и IDN. Этот пример не является расширением браузера или готовым антифишингом.
